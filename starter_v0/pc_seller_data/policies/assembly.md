## Compatibility check

Every custom build must pass a compatibility check before assembly. The check covers CPU socket versus mainboard socket, mainboard memory type versus memory type, graphics card length versus case clearance, and power supply wattage versus the graphics card recommendation.

## Assembly service

Assembly and burn-in testing costs 79 USD and adds 2 business days. The service includes cable management, BIOS update, and a 24 hour stress test.

## Store responsibility

If a build fails because the store shipped incompatible parts, the store covers return shipping and re-assembly. If the customer supplied their own parts, the store only guarantees the assembly labour.

## Overclocking

The store applies only the manufacturer profile. Aggressive manual overclocking voids the assembly warranty on the affected parts.
